<a id="background"></a>
## 📖 项目背景

大学物理实验是几乎所有理工科专业的必修课。实验本身或许有趣，但实验之后的**数据处理**，往往才是真正让人抓狂的部分——公式多、步骤繁、数据量大，一不小心就要从头再算一遍。

这个项目的起点，其实很普通。

大一时，我在做"平均值与不确定度计算"这个实验。那是我遇到的第一个需要反复计算残差、标准偏差、A 类不确定度、B 类不确定度、总不确定度的实验。手算一遍要十几分钟，中间错一个数就要全部重来。于是一气之下，我写了一段 Python 代码来帮我算。

后来室友们知道了，也拿去用了。再后来，我开始想：**其他实验其实也一样繁琐，为什么不干脆做一个可以不断扩展的小工具呢？**

于是就有了 **PhyCalc（格物算）**。

项目名取自《礼记·大学》中的"格物致知"。"格物算"既是"格物"与"计算"的结合，也算是我自己对这门课的一点小小反抗。

现在是大四刚开学，翻电脑时重新看到当年那段代码，想着不如把它整理成一个正式的项目，开源出来，**给更多正在被物理实验数据处理折磨的同学一点帮助**。

### 📌 关于当前版本与后续计划

目前项目**已初步成型**，完成了以下内容：

- 支撑整个框架的主菜单（支持章节 → 小节两级导航）
- 通用界面模板（`0.0_通用_generic_ui.py`）与通用计算模板（`0.0_通用_generic_core.py`）
- 三个正式实验：
  - 1.2 不确定度估算与测量结果表示
  - 1.4 常用的实验数据处理方法
  - 2.1 长度测量和体积测量

接下来我会**参照本项目指定的参考教材，逐步填充大学物理实验课程中的大部分实验**。由于每个实验的公式、输入项、输出项都不相同，需要一个个手动整理与测试，因此项目会以**渐进式**的方式持续更新——每完成一个实验，就以 commit 的形式推送到仓库，并在此 README 的"实验清单"中更新。

**关于打包发行版：**

原计划在项目成型后发布打包好的便携版程序（免 Python 环境，解压即用）。但由于目前实验数量还较少，为了不让大家下载一个只含少数实验的压缩包，**决定暂时仅发布源码**，供有兴趣、会一点 Python 的同学先行使用与测试。

**当仓库内的实验数量达到 5 ~ 10 个之后**，我会正式开始打包流程，发布 **v1.0 便携版**，并同步更新本 README 与 Releases 页面。在此之前，请直接使用下方的"完整源码"方式运行。

感谢理解，也欢迎一起参与建设 🙏

<a id="features"></a>
## ✨ 项目特点

- 🖥️ **图形化界面**：无需命令行基础，双击即用。
- 🌏 **中英双语**：一键切换界面语言。
- 🎚️ **实时可调**：字号、计算精度都可自由调整。
- 🧩 **高度可扩展**：任何人都可以按统一规范，为自己学校的实验添加新模块。
- 🧮 **纯计算模块独立可用**：不想运行完整程序的同学，可以单独下载计算文件，修改变量就能算。
- 📚 **参照指定教材开发**：所有实验均以指定教材为基准，方便对照检查。
- 🗂️ **章节 → 小节两级导航**：实验一多也能快速定位，不会在长列表里翻找。

## 📚 教材说明

### 关于项目所选用参考教材的一点说明

本项目的作者就读于**农林类院校**。我校大学物理实验课程使用的教材，是结合力学、热学、电磁学、光学、近代物理等方面的基础实验，以及传感器、信息技术等现代测量技术内容自行编写的校本教材，同时面向理工科非物理类专业与农林类专业。

需要**特别说明**的是：

> **我校的校本教材不作为本项目的参考教材。**

原因很简单：我大一上实验课时所用的那本教材，后来已经出售，手边没有留存。因此在着手整理这个项目时，我使用的是另外一本**内容体系更通用**的教材作为开发参照。

考虑到不同学校、不同校本教材在符号约定、公式写法、不确定度评定方式上都可能存在差异，本项目**不能保证与各位同学手头教材完全一致**，请在使用时以自己教材为准。

如果你所在学校使用的教材与我的参考教材不同，欢迎在 Issues 中说明，或者直接修改 `core_calculations/` 中对应的计算文件，使其与你们学校的要求一致。

> ISBN 978-7-04-046984-4.

因文件过大，所以无法直接上传仓库根目录。电子书仅供对照使用，请勿用于其他用途，也请大家支持正版。

<a id="source-code"></a>
## ① 完整源码（当前主要方式）

如果你想在本地运行源码，**或者想给自己学校的实验增加模块**，请使用这种方式。

### 环境要求

- Python **3.8+**（Tkinter 为标准库，无需额外安装依赖）
- 推荐使用 Anaconda + Spyder，或者 VSCode + Python 插件

### 下载与运行

```bash
git clone https://github.com/Celestiflare-Lucifer/PhyCalc.git
cd PhyCalc
python main.py
```

或者直接在 GitHub 页面点击 `Code → Download ZIP`，解压后运行 `main.py`。

### 完整项目结构

```
PhyCalc/
├── README.md
├── main.py
├── settings.json
├── ui_pages/
│   ├── 0.0_通用_generic_ui.py
│   ├── 1.2_不确定度估算与测量结果表示_uncertainty_estimation_ui.py
│   ├── 1.4_常用的实验数据处理方法_common_data_processing_ui.py
│   └── 2.1_长度测量和体积测量_length_and_volume_measurement_ui.py
└── core_calculations/
    ├── 0.0_通用_generic_core.py
    ├── 1.2_不确定度估算与测量结果表示_uncertainty_estimation_core.py
    ├── 1.4_常用的实验数据处理方法_common_data_processing_core.py
    └── 2.1_长度测量和体积测量_length_and_volume_measurement_core.py
```

### 命名规则

本项目使用 `n.m_中文名_英文名_xxx.py` 的命名方式：

- `n` = **章号**（整数，如 1、2、3）
- `m` = **节号**（整数，如 1、2、3；无节可写 0）
- `中文名` 与 `英文名` 之间用下划线分隔
- `xxx` = `core`（计算逻辑）或 `ui`（专用界面）

例如：

```
1.2_不确定度估算与测量结果表示_uncertainty_estimation_core.py
1.2_不确定度估算与测量结果表示_uncertainty_estimation_ui.py
```

主菜单会按 `(n, m)` 从小到大排序：

- **章节视图**：显示每一章，例如 `第 1 章 数据处理与不确定度估算`
- **小节视图**：点击章节后显示该章的小节，例如 `1.2 不确定度估算与测量结果表示`

> ⚠️ **两个以 `0.0_` 开头的模板文件会被主菜单自动跳过**，请勿删除它们。

### 如何添加一个新实验

添加一个新实验，**只需两步**：

#### 第 1 步：写计算逻辑（必需）

在 `core_calculations/` 目录下新建一个文件，命名格式为：

```
n.m_中文名_英文名_core.py
```

然后**直接复制** `0.0_通用_generic_core.py` 的内容到新文件，按注释修改以下两处：

1. **`UI_SPEC`**：填写实验标题、输入项、输出项。
2. **`calculate()`**：实现你的计算逻辑。

`UI_SPEC` 的字段含义：

```python
UI_SPEC = {
    'title': {'zh': '实验中文名', 'en': 'Experiment English Name'},
    'chapter': 7, 'section': 2,                 # 章节号（可选，文件名已带可省略）
    'inputs': [
        {
            'name': 'data',                     # 变量名，将作为 calculate 的参数
            'label': {'zh': '测量数据', 'en': 'Data'},
            'type': 'list',                     # 'list' / 'float' / 'int' / 'text' / 'choice'
            'initial': 6,                       # 初始显示几行
            'item_prefix': {'zh': 'x', 'en': 'x'},   # 每行前缀（会显示成 x_1、x_2…）
            'unit': '',                         # 单位（显示在输入框右侧）
            'hint': {'zh': '...', 'en': '...'}, # 顶部提示
            'default': []
        },
        {
            'name': 'instrument_error',
            'label': {'zh': '仪器误差', 'en': 'Instrument Error'},
            'type': 'float',
            'default': 0.01
        }
    ],
    'outputs': [
        {'name': 'avg', 'label': {'zh': '平均值', 'en': 'Average'}},
        # ... 更多输出
    ],
    'func': 'calculate'
}
```

> 💡 **提示**：你的 `calculate()` 函数**必须**接受 `UI_SPEC['inputs']` 中所有 `name` 作为参数，并返回一个字典，其键名**必须**与 `UI_SPEC['outputs']` 中的 `name` 对应。

保存后，**无需修改任何其他文件**，主菜单会自动识别新实验，并使用**通用界面**渲染交互页面。

#### 第 2 步（可选）：定制专属界面

如果你希望新实验的界面有**个性化的文字提示**（例如把输入框标题改为"钢丝长度"、"砝码质量"等），可以在 `ui_pages/` 目录下新建一个同名文件：

```
n.m_中文名_英文名_ui.py
```

**内容只需要复制通用模板的【A】区**（个性化配置区），通常只有十几行：

```python
LANG_OVERRIDE = None    # 若需新增提示文字，在此填写

UI_SPEC_OVERRIDE = {
    'inputs': [
        # 在这里重新定义输入项的标签、提示、单位等，覆盖 core 文件中的设置
    ],
}

DEFAULT_WINDOW_SIZE = "800x750"
```

保存后，主菜单会自动识别并使用这个专用界面。**不需要写任何界面代码。**

> ⚠️ **命名提醒**：主菜单**只识别符合 `n.m_中文名_英文名_core.py` / `n.m_中文名_英文名_ui.py` 格式的文件**。`n.m` 是决定排序的章节号；中文名与英文名之间的下划线是必要的分隔符。

<a id="core-only"></a>
## ② 纯计算模块：只想算一算

如果你：

- 只想**尽快算完当下实验的数据**；
- 不想下载整个项目；
- 或者想**修改代码使它更符合你们学校的要求**；

那么可以只下载 `core_calculations/` 里的某个计算文件。

### 使用步骤

1. 打开 [core_calculations 目录](../core_calculations)，找到你要的实验文件。
2. 点击文件右上角的 `Raw` 或 `Download` 按钮，下载单个 `.py` 文件。
3. 用 **Spyder / VSCode / PyCharm / IDLE** 打开。
4. 找到文件底部 `if __name__ == "__main__":`，直接在命令行里运行：

   ```bash
   python 1.2_不确定度估算与测量结果表示_uncertainty_estimation_core.py
   ```

5. 按提示输入数据即可。

### 也支持直接修改代码

如果你想在代码里直接写死数据（比如为了批量处理多组数据），可以修改 `main()` 中对应的变量赋值：

```python
data = [27.03, 27.08, 27.07, 27.01, 27.05]    # ← 直接填入你的数据
instr = 0.04                                   # ← 仪器误差
result = calculate(data, instr)
print(result)
```

> 这些文件**全部不依赖任何第三方库**，只要装了 Python 就能跑。

<a id="instructions"></a>
## 🛠️ 使用说明（通用功能）

不论使用哪种方式，程序都支持以下功能：

### 主界面

- **关于**：查看版本号、作者联系方式、项目说明。
- **设置**：
  - 切换语言（中文 / English）
  - 设置计算精度（默认保留 3 位小数）
  - 设置默认窗口大小（需重启生效）
- **A+ / A-**：放大 / 缩小字体（8 ~ 20 号，实时刷新）
- **章节 → 小节导航**：点击章节进入该章的小节列表，点击"← 返回"回到章节列表。

### 二级实验界面

- 左上角同样提供**语言切换**、**精度设置**、**字号调节**。
- 二级页面的设置**仅在当前页面生效**，关闭后不保存。
- 支持**同时打开多个实验页面**（包括同一实验的多个窗口），互不影响。
- 关闭主程序会关闭所有二级页面；关闭某个二级页面不影响其他页面。

### 输入提示

- **全部输入框留空** → 提示"请至少输入一个有效数据"
- **部分留空** → 空输入框自动忽略，不参与计算
- **输入非数字字符** → 提示"输入包含非数字字符，请检查"

<a id="templates"></a>
## 🧩 模板说明

本项目提供两个通用模板，供你快速扩展：

| 模板 | 位置 | 用途 |
|------|------|------|
| **通用界面模板** | `ui_pages/0.0_通用_generic_ui.py` | 复制【A】区即可定制专属界面 |
| **通用计算模板** | `core_calculations/0.0_通用_generic_core.py` | 复制后修改 `UI_SPEC` 和 `calculate()` |

两个模板都以 `0.0_` 开头，主菜单会**自动跳过**它们，不会把它们误认为正式实验。

模板内部注释非常详细，每一处需要修改的地方都有说明。如果你对 Python 有一点点基础，完全可以照着注释自己写一个新实验。

或者，也可以将模板和相关资料一同上传至 DeepSeek、豆包等 AI 软件，让 AI 帮你编写程序。

### v0.2.1

**版本号约定**：`MAJOR.MINOR.PATCH`。

其中：

- **PATCH**：新增实验、修复实验中的错误——属于"内容"层面的补充；
- **MINOR**：修改 `main.py` 或两个通用模板——属于"框架"层面的变更；
- **MAJOR**：正式打包发布，进入稳定版本阶段。

之所以把"新增实验"归为 PATCH，是因为本项目采用插件化结构：新增实验不影响已有实验的运行，也不改变扩展接口，属于对框架的内容填充。只有当框架本身（导航逻辑、模板接口、命名规范）发生变化时，才递增 MINOR。
