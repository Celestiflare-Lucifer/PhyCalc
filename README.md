# PhyCalc · 格物算

> **格物算：大学物理实验数据处理工具**
> 
> 让数据处理不再是实验报告里最让人头疼的那一步。

---

## 📖 项目背景

大学物理实验是几乎所有理工科专业的必修课。实验本身或许有趣，但实验之后的**数据处理**，往往才是真正让人抓狂的部分——公式多、步骤繁、数据量大，一不小心就要从头再算一遍。

这个项目的起点，其实很普通。

大一时，我在做“平均值与不确定度计算”这个实验。那是我遇到的第一个需要反复计算残差、标准偏差、A 类不确定度、B 类不确定度、总不确定度的实验。手算一遍要十几分钟，中间错一个数就要全部重来。于是一气之下，我写了一段 Python 代码来帮我算。

后来室友们知道了，也拿去用了。再后来，我开始想：**其他实验其实也一样繁琐，为什么不干脆做一个可以不断扩展的小工具呢？**

于是就有了 **PhyCalc（格物算）**。

项目名取自《礼记·大学》中的“格物致知”。“格物算”既是“格物”与“计算”的结合，也算是我自己对这门课的一点小小反抗。

现在是大四刚开学，翻电脑时重新看到当年那段代码，想着不如把它整理成一个正式的项目，开源出来，**给更多正在被物理实验数据处理折磨的同学一点帮助**。

---

## ✨ 项目特点

- 🖥️ **图形化界面**：无需命令行基础，双击即用。
- 🌏 **中英双语**：一键切换界面语言。
- 🎚️ **实时可调**：字号、计算精度、选项布局都可自由调整。
- 🧩 **高度可扩展**：任何人都可以按统一规范，为自己学校的实验添加新模块。
- 🧮 **纯计算模块独立可用**：不想运行完整程序的同学，可以单独下载计算文件，改改变量就能算。
- 📦 **提供打包好的便携版**：无需 Python 环境，解压即用。

## ① 发行版：便携式应用程序（推荐给大多数同学）

**无需任何环境配置，下载解压即用。**

### 下载

前往 GitHub 的 [Releases](../../releases) 页面，下载最新版本：

```
PhyCalc_v1.0.zip
```

### 使用步骤

1. 下载 `PhyCalc_v1.0.zip`。
2. 解压到任意文件夹（建议路径中**不要含有中文或空格**）。
3. 双击其中的 `PhyCalc.exe`（Windows）即可启动主界面。
4. 在主界面选择你要做的实验，进入二级页面，输入数据，点击“计算”。

## ② 完整源码：可以自行扩展（推荐给想折腾的同学）

如果你想在本地运行源码，**或者想给自己学校的实验增加模块**，请使用这种方式。

### 环境要求

- Python **3.8+**（Tkinter 为标准库，无需额外安装依赖）
- 推荐使用 Anaconda + Spyder，或者 VSCode + Python 插件

### 下载与运行

```bash
git clone https://github.com/<你的用户名>/PhyCalc.git
cd PhyCalc
python main.py
```

或者直接在 GitHub 页面点击 `Code → Download ZIP`，解压后运行 `main.py`。

### 完整项目结构

```
PhyCalc/
├── README.md
├── main.py                                  # 唯一启动文件（一级菜单）
├── settings.json                            # 自动生成，保存用户设置
├── ui_pages/                                # 二级交互界面
│   ├── 00_通用_generic_page.py              # 通用界面模板（所有实验共用）
│   └── 01_平均值与不确定度计算_average_uncertainty_page.py
└── core_calculations/                       # 纯计算逻辑
    ├── 00_通用_generic_core.py              # 通用计算模板
    └── 01_平均值与不确定度计算_average_uncertainty_core.py
```

### 如何添加一个新实验

添加一个新实验，**只需两步**：

#### 第 1 步：写计算逻辑（必需）

在 `core_calculations/` 目录下新建一个文件，命名格式为：

```
nn_中文名_英文名_core.py
```

其中 `nn` 是**两位数**的章节号（如 `02`、`03`…），中文名与英文名之间用下划线分隔。

例如，你想添加“用拉伸法测金属丝的杨氏模量”，可以命名为：

```
02_拉伸法测杨氏模量_youngs_modulus_core.py
```

然后**直接复制** `00_通用_generic_core.py` 的内容到新文件，按注释修改以下两处：

1. **`UI_SPEC`**：填写实验标题、输入项、输出项。
2. **`calculate()`**：实现你的计算逻辑。

`UI_SPEC` 的字段含义：

```python
UI_SPEC = {
    'title': {'zh': '实验中文名', 'en': 'Experiment English Name'},
    'inputs': [
        {
            'name': 'data',                    # 变量名，将作为 calculate 的参数
            'label': {'zh': '测量数据', 'en': 'Data'},
            'type': 'list',                    # 'list' 表示多个数据（可动态增删行）
            'initial': 6,                      # 初始显示几行
            'item_prefix': {'zh': '数据', 'en': 'Data'},  # 每行前缀
            'default': []
        },
        {
            'name': 'instrument_error',
            'label': {'zh': '仪器误差', 'en': 'Instrument Error'},
            'type': 'float',                   # 'float' 或 'int'，单值输入
            'default': 0.01                    # 输入框默认值
        }
    ],
    'outputs': [
        {'name': 'avg', 'label': {'zh': '平均值', 'en': 'Average'}},
        # ... 更多输出
    ],
    'func': 'calculate'                        # 计算函数名
}
```

> 💡 **提示**：你的 `calculate()` 函数**必须**接受 `UI_SPEC['inputs']` 中所有 `name` 作为参数，并返回一个字典，其键名**必须**与 `UI_SPEC['outputs']` 中的 `name` 对应。

保存后，**无需修改任何其他文件**，主菜单会自动识别新实验，并使用**通用界面**渲染交互页面。

#### 第 2 步（可选）：定制专属界面

如果你希望新实验的界面有**个性化的文字提示**（例如把输入框标题改为“钢丝长度”、“砝码质量”等），可以在 `ui_pages/` 目录下新建一个同名文件：

```
nn_中文名_英文名_page.py
```

例如：

```
02_拉伸法测杨氏模量_youngs_modulus_page.py
```

**内容只需要复制通用模板的【A】区**（个性化配置区），通常只有十几行：

```python
LANG_OVERRIDE = None    # 若需新增提示文字，在此填写

UI_SPEC_OVERRIDE = {
    'title': {'zh': '拉伸法测杨氏模量', 'en': "Young's Modulus"},
    'inputs': [
        # 在这里重新定义输入项的标签，覆盖 core 文件中的设置
    ],
}

DEFAULT_WINDOW_SIZE = "650x500"
```

保存后，主菜单会自动识别并使用这个专用页面。**不需要写任何界面代码。**

> ⚠️ **命名提醒**：请务必使用统一命名格式，主菜单**只识别符合 `nn_中文名_英文名_core.py` / `nn_中文名_英文名_page.py` 格式的文件**。`nn` 是决定排序的章节号；中文名与英文名之间的下划线是必要的分隔符。

## ③ 纯计算模块：只想算一算（推荐给懂点代码的同学）

如果你：

- 只想**尽快算完当下实验的数据**；
- 不想下载整个项目；
- 或者想**修改代码使它更符合你们学校的要求**；

那么可以只下载 `core_calculations/` 里的某个计算文件。

### 使用步骤

1. 打开 [core_calculations 目录](../core_calculations)，找到你要的实验文件。
2. 点击文件右上角的 `Raw` 或 `Download` 按钮，下载单个 `.py` 文件。
3. 用 **Spyder / VSCode / PyCharm / IDLE** 打开。
4. 找到文件底部 `if __name__ == "__main__":` 里的 `main()` 函数，或者直接在命令行里运行：
   ```bash
   python 01_平均值与不确定度计算_average_uncertainty_core.py
   ```
5. 按提示输入数据即可。

### 也支持直接修改代码

如果你想在代码里直接写死数据（比如为了批量处理多组数据），可以修改 `main()` 中对应的变量赋值：

```python
data = [1.234, 1.235, 1.233, 1.236, 1.234, 1.235]   # ← 直接填入你的数据
instr = 0.01                                          # ← 仪器误差
result = calculate(data, instr)
print(result)
```

## 🛠️ 使用说明（通用功能）

不论使用哪种方式，程序都支持以下功能：

### 主界面

- **关于**：查看版本号、作者联系方式、项目说明。
- **设置**：
  - 切换语言（中文 / English）
  - 设置计算精度（默认保留 3 位小数）
  - 切换选项布局（按钮模式 / 文字模式）
  - 设置默认窗口大小（需重启生效）
- **A+ / A-**：放大 / 缩小字体（8 ~ 20 号，实时刷新）

### 二级实验界面

- 左上角同样提供**语言切换**、**精度设置**、**字号调节**。
- 二级页面的设置**仅在当前页面生效**，关闭后不保存。
- 支持**同时打开多个实验页面**（包括同一实验的多个窗口），互不影响。
- 关闭主程序会关闭所有二级页面；关闭某个二级页面不影响其他页面。

### 输入提示

- **全部输入框留空** → 提示“请至少输入一个有效数据”
- **部分留空** → 空输入框自动忽略，不参与计算
- **输入非数字字符** → 提示“输入包含非数字字符，请检查”

## 🧩 模板说明

本项目提供两个通用模板，供你快速扩展：

| 模板 | 位置 | 用途 |
|------|------|------|
| **通用界面模板** | `ui_pages/00_通用_generic_page.py` | 复制【A】区即可定制专属界面 |
| **通用计算模板** | `core_calculations/00_通用_generic_core.py` | 复制后修改 `UI_SPEC` 和 `calculate()` |

两个模板都以 `00_` 开头，主菜单会**自动跳过**它们，不会把它们误认为正式实验。

模板内部注释非常详细，每一处需要修改的地方都有说明。如果你对 Python 有一点点基础，完全可以照着注释自己写一个新实验。
